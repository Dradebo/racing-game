# Racecraft Language Boundary

Striving Observation has its own vocabulary. Agents working in this directory must not import metaphors, labels, or operating language from unrelated projects unless that text is part of a project's evidence record.

## Canonical UI vocabulary
- Season
- Race
- Circuit
- Lap
- Split
- Replay
- Pit wall
- Starting grid
- Finish line
- Podium
- Pit stop / pit hold
- Yellow flag
- Red flag
- Stale / no signal
- Parked
- Waiting on external
- Waiting on me
- Next legal lap
- Baton (state handoff object only; not generic motivational copy)
- Steward decision (verification or reconciliation only)

## Avoid in renderer copy
Do not use language borrowed from adjacent systems such as:
- archaeology
- coffers
- garage as capability bank
- refinery / ingots / mining / fishing
- shopfront / proof bank / portfolio language
- Q-City district language
- sales / engagement terminology
- identity-system metaphors

Project-specific nouns are allowed only as data: project names, artifacts, evidence labels, and source descriptions.

## Rule
UI copy should describe race state, not explain the broader personal operating system.

If a concept cannot be expressed cleanly with the canonical race vocabulary, add it to the state model first rather than borrowing a metaphor from another project.
